# Home

## Overview
The Poompuhar College TC Portal project is designed to streamline the process of issuing Transfer Certificates (TC) for students. 

## Purpose
The primary aim of the portal is to provide an online platform for students to apply for their transfer certificates, making the process efficient and user-friendly.

## Technology Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Hosting**: Heroku

## Key Features
- User authentication for students
- Application status tracking
- Notification system for updates on TC requests
- Admin dashboard for managing applications

The portal enhances the efficiency of the process and serves as a valuable resource for students transitioning between educational institutions.
